# Flask To-Do App

A simple web application built with **Flask** to manage tasks.  
This project allows you to add, list, mark as done, and delete tasks through a web interface.

---

## 🛠 Features

- Add new tasks via a web form  
- List all tasks  
- Mark tasks as completed  
- Delete tasks  
- Simple and clean interface with CSS styling
